## Exploration and recommendation

**Question.** How can the existing Gheed side quest remain a useful, recognizably mercantile treasure opportunity when its five gold gambles and anonymous magic reward contradict GDD economy rules? Keep the five-part progression and Gheed identity, add a useful outcome, and fit the existing mobile journal/source architecture. [S1–S5]

Precedents are design analogies, not imported mechanics or fresh external research: D2 Gheed supplies the shady treasure-merchant voice, but his paid unknown-item loop conflicts with this GDD; PoE's deterministic vendor recipes demonstrate readable material value, but a general exchange interface would expand scope; D2's finite quest rewards demonstrate deliberate one-time payoff, while opaque hand-ins are inappropriate for this journal-first mobile flow. The repository's accepted counted-source quests supply the actual implementation precedent. [S10–S20]

Recommend **A**, named **Gheed's Salvage Deal / 基德的寻宝交易**. It preserves the authored count 5, quest/objective IDs, Act/giver and XP1000 while replacing the unsupported economy/reward mechanism. A bare Talk reward would be smaller but would erase meaningful five-part play and physical proof. Gheed bargains over overlooked valuables; he does not accept a stake, sell unidentified gear, roll odds or offer repeat purchases.

## 1. Overview

Turn `quests/side-act1-gheeds-gamble` into a finite optional salvage commission. Gheed wants five marked lots recovered from the compact Cold Plains. Each explicit Recover earns one nongear quest-ledger source; the fifth completes collection but pays nothing. A separate journal Claim exchanges the five lots for exactly `{xp:1000,gemShards:1,wishstones:10}` once. The result uses the existing `gem-shard` wallet and gem-fusion sink. “Currency-only” below describes the replacement **itemization reward**: preserve already-authored XP1000 and its existing eligible merc share, but add no ordinary gear, typed rune/gem, material stack or service. This fixed one-shard reward is the smallest positive catalyst amount and is explicitly proposed for ratification. [S2,S8–S9,S13–S18,S33–S37]

## 2. Player fantasy

“I spotted the value everyone else passed by, and made a useful deal with Gheed.” His sharp-eye treasure-merchant voice already appears in both town locales. Preserve that voice through named lots and a known commission; replace the misleading gold/odds/magic promise in the quest and any surfaced Gheed dialogue. [S23–S24]

Discovery and Fantasy come from the five individually named finds. Competence comes from a truthful0/5→5/5 counter and exact wallet gain. Autonomy comes from choosing when to exchange. This serves GDD loot/build inputs and light text/mobile interaction without adding direct offline rewards. The one-time optional detour supports the combat/progression loop; it is not a new core currency market or a pacing claim. No new artwork or image generation is needed. [S1]

## 4. Formulas

Let the literal source set be`S={lot-1,…,lot-5}` and`N=5`. `held=Σ1[state(s)=owned]`, `consumed=Σ1[state(s)=consumed]`, `recovered=held+consumed`, each integer in`[0,5]`. Counts derive from source identities, never a saved counter. New collection completion is`held=5`; Claim eligibility is`completed ∧ !claimed ∧ held=5` with exact authority and ordinary readiness.

One successful Claim changes`gem-shard` from`B` to`B+1` and cumulative hero XP through existing progression by`1000`; reject if any required arithmetic is nonfinite, negative where invalid or exceeds safe integer bounds. If the existing eligible actual fielded merc recipient exists, award`floor(1000×0.75)=750` merc XP using the existing share/cap/growth semantics; no merc means no invented recipient or later deferred award. Ordinary hero level cap, points from genuine level-ups and stat/cache composition remain the existing XP system. No new direct stats or restorative effect is authored. [S17,S25]

At prebalance`B=2`, success yields`3` and exactly five consumed sources. A repeat yields`3`, no XP and no new ledger entry. A failed payment yields the previous participating state, with independent unrelated updates conserved.
