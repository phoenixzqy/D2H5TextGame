# UI remaster art brief

The interface should feel built from carved charcoal stone, blackened iron,
oxblood leather, tarnished bronze and bone inlay. Preserve a clear hierarchy:
stone provides structure, leather supports text-heavy interiors, iron carries
navigation, crimson marks primary actions, bronze traces important edges.

Use the accepted generated materials throughout screens and shared controls.
Carry the same border weight, corner cuts, inset shadows and warm highlight
across buttons, headers, dialogs, tooltips, navigation, inventory slots and
progress meters. Decorations should frame live game information, leaving it
readable at 360 px width. Health and resource colors retain their semantics.

Use original interrupted rails, offset diamonds and restrained thorn cuts for
ornament. Avoid copying Diablo logos, specific emblems or recognizable buttons.
Keep text live, translated and selectable. Focus, selected, disabled and danger
states need clear visual distinction alongside the texture family.

The sanctuary background is atmospheric and should sit behind a dark veil;
text-bearing surfaces need a stable opaque backing. The generated frame can
use a 40 px nine-slice border. The cropped header strip can stretch horizontally
as secondary decoration with a dark overlay. Full source and derivative records:
[ui-remaster-sources/SOURCE.md](./ui-remaster-sources/SOURCE.md).
