desktop/mobile preview artifacts match byte-for-byte per locale/rank/stage.

actually closes. It reopens the same profile with the network disabled. A cached
image document permits read-only durable IndexedDB observation before app
startup; all seven persistent domains equal the exported state. App navigation
then succeeds with `navigator.onLine === false`, an activated service-worker
controller and no bridge. The reconciled startup disk clock supplies the exact
subminute `offlineTime` delta. Continue and a subsequent export match every
persistent domain after only the documented clocks/delta are accounted for.

observes a charge-bearing frame followed by charge disappearance and positive

regeneration, an orb or expiry. Exact zero-enemy-MP, paid-stack ownership and
floored/clamped recovery causality come from the separate reviewed DEV/native
witnesses. The production supplement establishes public controls, offline
